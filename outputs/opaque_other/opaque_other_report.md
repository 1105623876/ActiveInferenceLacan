# Opaque Other Coupling Report

## 研究目标

检验：当他者 Symbolic 位置只能通过带噪社会观察被推断时，
`C_S := q(s_j)` 是否仍能产生 Symbolic 共识，以及这种错误是否不同于 noisy 对真值的逐步涂糊。

推断对象是位置 `s_j`，不是欲望 `C_j`。

## 机制

| mechanism | C_S | 他者是否可读 |
|-----------|-----|--------------|
| off | 保持初始 onehot | 不读 |
| hard | onehot(true S_j) | 直接读真值 |
| noisy | 0.8·onehot(true S_j)+0.2·uniform | 读真值后涂糊 |
| infer(σ) | q(s_j) = filter(A_social(σ), o, D_other) | 只读带噪 o |

- 环境：isolated；A→B→C sequential；agent / A / B / weights 与 factorial 一致
- seeds 0..19，50 steps，收敛阈值 sym_var < 0.01
- D_other 初值为均匀分布；v1 不使用他者运动模型 B
- infer@1.0 与 hard 的轨迹不必逐 seed 相同（社会通道采样会消耗 RNG），只要求统计接近
- Phase 0 体检：PASS

## 最重要的观察

1. **共识不要求读准他者位置**。isolated+[5,2,6] 上 infer@0.40 仍有 15/20 收敛，全程 misID=0.566，后半段 0.489，共识后 0.395。若共识后 misID 仍高，则是共享秩序但不读准他者；若塌到接近 0，则只是路上认错。
2. **不透明度主要拖慢、而不是关掉共识**。[5,2,6] TTS：hard 10.1，infer@1 13.2，infer@0.40 33.7；[8,8,8] infer@0.40 仍 20/20 收敛。
3. **noisy 的 misID=0 是结构事实**：它先读真值再涂糊，argmax 不会错。
   与 infer 的差别首先是“会不会认错”，不是收敛率（收敛 CI 多半重叠）。
4. infer@1 与 hard 收敛率接近，但 [5,2,6] 终态不同：hard S=0 95%，infer@1 other_conv 60%。σ=1 只保证通道可读，不保证落入同一个 endpoint。

## 主张与停机

### 当前证据支持的说法

- isolated + off 仍不收敛：没有通道时不会凭空对齐。
- infer@σ=1 的 misID 接近 0：无噪社会通道下位置推断塌回可读真值。
- σ 下降时 misID 上升：不透明度进入了信念，不是假通道。
- 至少在一个初态上，infer 与 noisy 在收敛 CI 或（misID + 错误持续性）上可区分。

### 不应写

- 这不是大他者、欲望或 Che vuoi? 的形式化。
- 不写 phase transition；σ 只是社会通道清晰度。
- S=0 / S=8 仍称 endpoint regime，不是 attractor。
- noisy 的 argmax 几乎总是真值，故 misID≈0 是该 baseline 的结构事实，不是“更准确的推断”。

### Phase 2 门

**打开**：可做噪声匹配（把 noisy 的 ε 调到与某档 infer 的 H(C) 接近），只在 isolated 上做。
