# Environment Initial-State Sensitivity Report

## 实验设置

固定 **isolated + C_update_on** 条件（factorial 主实验中的最强收敛条件），
固定 agent 配置（C_R/C_S/C_I/D_R/D_S/D_I/weights/policy_len/T）和 seed 集合（0..19），
只改变环境初始状态 `[env_r0, env_s0, env_i0]`，观察：

- Symbolic 收敛率是否对初态敏感；
- 最终 Symbolic 方差；
- 三个 agent 的最终状态；
- 是否总是落到同一个终态。

### 公平性

- agent 配置完全沿用 factorial 主实验（与 v2 `run_triadic_isolated` 一致）；
- 每 seed 每 env_init 重新初始化所有环境、agent 参数和 observation；
- 收敛阈值 `sym_var_final < 0.01`（与 v2 Exp4 / factorial 主实验一致）；
- 20 seeds (0..19)，50 steps。

## 声明

1. 本实验固定 isolated + C_update_on，仅扫描环境初始状态。
2. 不修改 deep_experiments_v2.py；复用 factorial_env_symbolic.py 的模型函数。
3. 结果不构成拉康理论的证明，是 toy model 上的计算观察。
4. 基于 20 seeds 的聚合统计，非单 seed 轨迹。
